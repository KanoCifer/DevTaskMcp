| 视角               | 抓什么                                                             |
| ------------------ | ------------------------------------------------------------------ |
| **Reuse**          | 新代码重复了 codebase 已有能力——指出已有的 helper 可改调           |
| **Simplification** | 冗余/可推导状态/复制粘贴变体/深层嵌套/留下死代码——指出等价更简形式 |
| **Efficiency**     | 冗余计算/可并行的串行/热路径阻塞/闭包大包——指出更便宜的写法        |
| **Altitude**       | 修复深度不够的特殊 case——偏好通用化底层机制而非叠特殊 case         |
